DETAIL 03 · PIPELINE & ISOLATION

后台提取如何避免反向触发压缩

Pipeline 使用独立内部会话执行 L1→L3；Offload 识别该会话并跳过，结果只在下一轮 recall 时进入前台。

双触发保证及时性

队列达到阈值时立即执行；流量较低时由 idle timer 兜底，避免少量会话长期滞留。

内部会话必须隔离

Pipeline 的 LLM 请求仍会经过插件钩子，Offload 通过 session 标识主动跳过，防止提取过程再次压缩自己。

跨轮可见而非本轮回写

L1、L1.5、L2、L3 写入持久层和向量索引后，由下一轮并行 recall 统一读取。
